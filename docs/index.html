About

GeoDash is a Python recreation of the popular game Geometry Dash, built with pygame. It features a 1280×720 menu with the original UHD artwork, a complete level library, local progress tracking, and customizable garage colors. The recreation imports levels from the local Geometry Dash installation and supports playing with reference input recordings.

Key Features

Original Menu

1280×720 interface with level carousel, full library, and music settings using original artwork.

22+ Levels

All 22 main levels, The Challenge, and Tower levels imported from your Steam installation.

Garage & Customization

Icon-color garage with persistent colors that apply to gameplay, animated parts, and effects.

Local Progress

Track your progress locally with no internet required to play.

Reference Validation

Test your implementation against recorded input sequences from the original game.

Original Game Access

Quick access to the original Geometry Dash game without modifying any files.

Getting Started

GeoDash requires Python 3 and a local Geometry Dash installation.

Installation

git clone https://github.com/Sodium516/GeoDash.git cd GeoDash python3 -m venv .venv .venv/bin/python -m pip install -r requirements.txt

Running the Game

.venv/bin/python geometry_dash.py

Controls

  • Space / Up / Left Mouse: Jump/Act
  • Left / Right: Select level or practice section
  • Enter: Play selected level
  • R: Retry level
  • P: Toggle practice mode
  • Tab: Pause
  • M: Toggle mute
  • Escape: Return to menu

Verification & Testing

.venv/bin/python -m unittest -q .venv/bin/python verify_level.py .venv/bin/python verify_level.py --level 17

Compatibility

Currently, 13 levels have passing reference routes:

  • First 11 main levels
  • Electroman Adventures
  • Clubstep

Other levels have known physics mismatches. See reference/compatibility_report.json for detailed results.
